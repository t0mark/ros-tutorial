ROS SIM웹 도구 사용 안내

ROS 웹 시뮬레이터

ROS를 설치하지 않고 브라우저에서 명령어와 노드 간 통신을 실습합니다. PC의 최신 Chrome·Edge·Firefox에서 키보드를 사용해 실습하세요.

시뮬레이터 실행 → · ROS 2 기초 읽기 · 교재 목차

첫 실습: Topic 통신

  1. 시뮬레이터의 첫 터미널에 ros2 run demo_nodes_cpp talker를 입력합니다.
  2. Ctrl+Shift+E로 터미널을 추가하고 ros2 run demo_nodes_cpp listener를 입력합니다. 전송한 메시지가 수신되는지 확인합니다.
  3. 터미널을 하나 더 열어 ros2 topic list, ros2 node list를 실행합니다.
  4. rqt_graph를 실행하면 새 창에 노드와 토픽의 연결이 표시됩니다.
  5. 실행 중인 터미널에서 Ctrl+C를 누르면 해당 노드가 종료됩니다.

Turtlesim 조종

  1. ros2 run turtlesim turtlesim_node를 실행합니다. 브라우저가 새 창을 차단하면 이 사이트의 팝업을 허용하고 노드를 종료한 뒤 다시 실행하세요.
  2. 다른 터미널에서 ros2 run turtlesim turtle_teleop_key를 실행합니다.
  3. 조종 명령을 실행한 터미널에 포커스를 둔 채 방향키로 거북이를 움직입니다.

왼쪽 튜토리얼의 Hello Topic·Turtlesim 탭에서 단계별 설명과 복사할 명령어를 볼 수 있습니다. Alt+←/→로 터미널을 이동하고 Ctrl+D로 닫습니다.

실습 범위와 초기화

JavaScript로 ROS 2 Humble의 일부 CLI 동작을 재현합니다. 실제 ROS·DDS·리눅스 셸·Python 실행 환경은 아니므로 실제 장치 연결, 패키지 설치와 빌드, 임의의 프로그램 실행은 지원하지 않습니다. 일부 명령은 학습용으로 단순화되어 있습니다.

시뮬레이션 상태는 새로고침하면 초기화됩니다. bag record는 수신 메시지 수만 표시하며 파일 저장·재생은 지원하지 않습니다. 실습은 시뮬레이터 탭 하나에서 진행하세요.
