전자 시스템 이론

순서대로 읽고, 각 장 끝의 확인 문제로 점검하세요. 체크한 진행 상황은 이 브라우저에 저장되어 아래 목록에도 표시됩니다.

본문

본문 챕터 구성은 준비 중입니다.

부록

현재 읽을 수 있는 자료입니다. 컴퓨터 시스템과 데이터 통신 부록은 추가 구성 예정입니다.

  • LINUX

    리눅스 첫걸음

    터미널 사용부터 파일·디렉터리, 사용자와 권한, USB 장치와 udev, 입력과 출력(재지정·파이프), 환경 변수와 .bashrc, 프로세스, 검색과 압축, vi까지.

    아직 시작 전
  • IPC

    프로세스 간 통신

    코드가 프로세스가 되는 과정과 메모리 구조부터 파이프·시그널, 공유 메모리와 동기화, 네트워크와 소켓, 그리고 ROS가 통신을 추상화하는 방식까지.

    아직 시작 전
  • ROS2

    ROS 2 기초

    ROS 2의 기본 개념과 그래프, 명령어와 도구(rqt · RViz2 · bag), Python 패키지와 colcon 빌드, Topic·Service·Action과 QoS·실행기, 노드·launch·설정 파일로 나누는 구조, 그리고 URDF와 TF2까지.

    아직 시작 전

웹 도구

  • ROS SIM

    ROS 웹 시뮬레이터

    ROS 설치 없이 브라우저에서 멀티 터미널, Topic 통신, Turtlesim과 rqt_graph를 실습합니다.
  • CIRCUIT

    회로도 작업실

    소자를 배치하고 핀을 연결해 회로 그림을 만듭니다. SVG 소자 등록, 공통 JSON 편집과 교재용 SVG 출력을 지원합니다.
진행 상황은 기기·브라우저마다 따로 저장됩니다.
